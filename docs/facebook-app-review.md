## What the app actually does

The signed-in user connects a Facebook Page through Facebook Login for Business in Smart Scheduler, selects a Page returned by Meta, chooses a photo or portrait video and a future time, and schedules it. The server stores Page credentials under that user's account. At delivery time it sends a photo to the Page photos API or uploads a Page Reel, then tracks the result in Content Timeline. The AI Agent can read details and recent posts from a connected Page. The scheduler currently supports Page photos and Reels, not text-only posts or personal profiles.

## Permission explanations

These match the explanations already present in the Meta draft. Check them against the current production flow before submitting.

### `pages_show_list`

After the user authorizes Facebook Login for Business, the server calls `/me/accounts`. Smart Scheduler shows only Pages where the user has a content creation task so the user can select the destination for a scheduled photo or Reel. Page tokens are stored server-side under that user's account and are not returned to the browser.

### `pages_manage_posts`

The user chooses their connected Page, media, caption, and scheduled time. At that time the server uses the selected Page access token to publish the approved photo or Reel. The app displays delivery status in Content Timeline. It does not publish to a personal profile or a Page the user did not connect.

### `pages_read_engagement`

For the Page connected by the user, the app reads the Page's name, description, website, contact fields, and recent Page posts. This gives the business owner Page context in the AI Agent and helps them confirm the selected Page before scheduling. The app does not request follower identities or private messages for this flow.
